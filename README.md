# 収支管理

個人専用の収支管理アプリ(PWA)。データは端末のブラウザ内(IndexedDB)にだけ保存され、外部には送信されない。

## 考え方

- **支出** はカテゴリ(何に払ったか)と目的タグ(何のためか)で記録する。
- **クレジットカード** は使った日に支出として記録する。引き落としは「銀行 → カード」の振替なので、支出は二重に数えない。
- **振替**(チャージ、ATM引き出し、カード引き落とし、NISA積立)は収支に入らない。
- **立替**(出張費など)は収支から除外し、収入源「立替精算」の入金と紐付ける。差額だけが精算した月の収支に残る。
- **現金** は収入・支出だけ記録し、残高は管理しない。
- **ポイント払い** は実際に払った金額だけを記録する。

## 開発

```
npm install
npm run dev      # 開発サーバー
npm test         # 計算ロジックのテスト
npm run build    # dist/ に本番用を出力
npm run preview  # 本番ビルドの確認
```

`main` ブランチに push すると `.github/workflows/deploy.yml` が GitHub Pages に公開する
(リポジトリの Settings → Pages → Source を「GitHub Actions」にしておく)。

## 構成

- `src/domain/` 残高・カード引落・定期予定・集計・バックアップの計算(画面に依存しない)
- `src/db/` IndexedDB(Dexie)の定義と初期データ
- `src/pages/`, `src/components/` 画面
